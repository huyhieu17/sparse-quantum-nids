# Controlled CPU simulator timing benchmark

Scope: all four frozen v11 datasets, dense / adaptive16 / adaptive8 projected encoders and Z7r2 Pegasos. Same stratified 200 training rows (seed 1301) and uniform random 20 test rows (seed 1302) within each dataset, no test-label selection. This is a bounded timing workload, not the full 2,000-row accuracy experiment or reproduction of the paper's absolute times.

Three sequential timed repetitions of identical workload and random seed 11; rotate method order. Nairobi, Lagos, Perth noise snapshots. Aer density_matrix with physical gate/thermal/readout noise, one simulator thread, one experiment/shot parallel worker, batch cap 32. BLAS/OMP threads fixed to one. No simultaneous benchmark jobs. Warm up simulator once per method/backend before timing. Repetitions measure runtime variability, not independent accuracy runs.

Actual Aer measurement and counts: projected uses Z/X, 512 shots each (1,024/input); Pegasos uses 1,024/overlap. No factorized Z7 shortcut, precomputed probability cache or simulated binomial shortcut. Z7 uses block-preserving mapped forward and inverse templates from v11, 100 Pegasos steps, C=1,000, kernel offset=1. No kernel caching except self-identical input kernel=1, consistently with v11. Projected SVC fixed C=10, gamma=1/30, balanced weights; no hyperparameter search or validation threshold calibration. Frontends loaded from frozen v11, previously fit on 2,000 train rows: 200 here is classifier timing workload, not total frontend label budget.

Record circuit synthesis/mapping, quantum simulator execution plus count extraction, classical fit/predict, total train/predict pipeline wall time, circuits, shots, references. Quantum time is a nested component of train wall time for Pegasos. Train total excludes frozen preprocessing, data load, backend/noise initialization, initial warmup, search and report writing. Predict wall includes new query circuit preparation, simulator and classical scoring; reference representations prepared during train are reused. Batch latency and throughput per sample are not single-request latency. Disk prediction/results saving excluded.

This benchmark compares complete algorithms at their native shot budgets; a separate per-circuit time is descriptive, not an equal-work accuracy comparison. Report all methods including regressions; CPU emulator speedup does not establish QPU latency or quantum advantage. Results are supplementary and cannot inherit v11/v12 full-data accuracy.
